# 실행 파일(exe)로 쓰기 — 선택 · Non Archive(폴더형)

> **먼저 권하는 방법은 「HTML 한 파일」입니다.**
> 도구 사이트의 「설정 → HTML 한 파일로 받기」로 받은 `data10-10_회의록요약도우미.html` 을 PC 에 두고 더블클릭하면 됩니다.
> 설치도 실행 파일도 없어 보안 프로그램에 걸릴 일이 가장 적습니다.
> 이 폴더는 그 파일을 쓸 수 없고 꼭 exe 가 필요할 때를 위한 것입니다.

## 무엇을 만드나요

- `run_local.py` — 파이썬 표준 라이브러리만 씁니다. 이 도구의 웹 파일(index.html · css · js · vendor · dist 의 HTML 한 파일)을 **이 PC 안에서만 열리는 주소**(기본 `http://127.0.0.1:18610/`)로 띄우고 기본 브라우저를 엽니다. 이 도구 파일 말고는 내보내지 않습니다.
  검은 창(콘솔)이 열려 있는 동안 도구가 돌고, 창을 닫으면 멈춥니다. 다른 PC 에서는 이 주소에 들어올 수 없습니다.
- `build_exe.bat` — `run_local.py` 와 웹 파일을 PyInstaller 로 묶습니다.
  - `--onedir` : 실행 파일 하나로 압축하지 않고 **폴더형**으로 만듭니다(실행할 때 임시 폴더에 풀지 않음).
  - `--noarchive` : 파이썬 모듈을 PYZ 묶음(Archive)에 넣지 않고 `.pyc` 낱개 파일로 둡니다.
  - 둘 다 「압축 · 자기 풀기」 모양을 없애 보안 프로그램의 오탐을 줄이려는 설정입니다. 다만 오탐이 **반드시** 사라진다고 약속할 수는 없습니다.

## Windows 에서 만드는 순서

1. Python 3.10 이상을 설치합니다(python.org, 설치할 때 「Add python.exe to PATH」 켜기).
2. 이 리포를 PC 에 받고 `tools\local-exe` 폴더에서 `build_exe.bat` 을 더블클릭합니다(PyInstaller 를 pip 로 설치하므로 처음 한 번은 인터넷이 필요합니다).
3. `tools\local-exe\exe-out\MeetingMinutes\` 폴더가 생깁니다. **폴더를 통째로** 쓸 자리로 옮기고 `MeetingMinutes.exe` 를 더블클릭합니다.
   - 폴더 안의 `_internal` 을 지우거나 exe 만 따로 옮기면 돌지 않습니다.
4. 실행 파일 없이 바로 써 보려면: 파이썬이 있는 PC 에서 `python run_local.py` (다른 포트는 `python run_local.py --port 8765`).

## 알아 두세요

- **회사 보안 정책에 따라 이 방법도 막힐 수 있습니다.** 서명 없는 exe 는 실행 자체가 막히거나 지워질 수 있습니다. 그럴 때는 IT 부서에 코드 서명 또는 보안 프로그램 예외(폴더 경로 · 파일 해시) 등록을 요청해야 할 수 있습니다. 그 전에 HTML 한 파일을 먼저 써 보세요.
- 판을 올리면(새 기능 · 고침) exe 를 **다시 만들어야** 합니다. HTML 한 파일은 새 파일로 덮어쓰기만 하면 됩니다.
- 회의록은 브라우저 저장소에 남는데, 저장소는 주소(포트 포함)마다 따로입니다. 그래서 늘 같은 포트(18610)로 띄웁니다. 그 포트를 다른 프로그램이 쓰고 있으면 빈 포트로 띄우고 창에 알리는데, 그 주소에서는 **지난번 회의록이 안 보입니다** — 다른 포트로 고정하려면 바로 가기에 `MeetingMinutes.exe --port 8765` 처럼 넣으세요. 옮길 때는 「설정 → 백업 · 옮기기」의 JSON 을 씁니다.
- HTML 한 파일(file://)과 실행 파일(127.0.0.1)은 주소가 달라 **회의록 저장소도 따로**입니다. 둘 사이도 백업 JSON 으로 옮깁니다.
- 이 주소(`127.0.0.1`)로 열면 로그인 없이 바로 씁니다(내 PC 로 봄).
- 사내 AI 서버로 자동 보내기를 쓰려면 그 서버가 이 주소(`http://127.0.0.1:포트`)에서 오는 요청을 허용(CORS)해야 합니다. 포트를 고정해 두면 IT 에 허용을 요청하기 쉽습니다.
- 이 폴더의 확인 범위: 개발 PC(macOS)에서 `python3 run_local.py` 가 서버를 띄우고 페이지가 열리는 것까지 확인했습니다. Windows exe 는 개발 PC 에서 만들 수 없어 **만들어 보지 않았습니다** — Windows 에서 위 순서로 만들어 주세요.
